# STM32计算器实现

### 使用库
libtouch_filter, libtouch_model

### 实现功能

**按键读取**

MCU时钟读取按键通道状态，再与物理按键相对应

**屏幕驱动**

初始化后向LCD1602发送0x02进入4位模式，把每个字节拆分成高低4位分别发送 \
**Feature**: 利用CGRAM，在屏幕上显示非ASCII字符

**串口输入模式**

在主界面按Shift+0，进入串口模式 \
将STM32使用USB连接至电脑后，用串口工具发送任意文本，将显示在屏幕上

**表达式解析**

使用递归下降解析器 \
支持四则运算、括号处理、根号、指对、三角及复数运算 \
处理时将所有表达式视为复数，但未开启复数模式将限制输入输出范围为实数域 \
按Mode进入复数模式后进行复数域运算

**Feature: 解一元二次方程**

在主界面按Shift+.进入解方程模式 \
依次输入a，b，c，按EXE，计算器将给出方程ax^2+bx+c=0的两个根

**Feature: 定积分**

在主界面按Shift+"x10^"进入定积分模式 \
输入下界，上界，表达式（以FMT代替x），计算器将给出该定积分的值 \
使用200段的复合Simpson公式进行计算

### 不足
1. 无法处理省略了乘号的表达式
2. 右括号未闭合会直接报错
3. Mode、Format功能未完整实现
4. 偶尔会出现按键识别错位
