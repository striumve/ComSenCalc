# STM32计算器实现

### 使用库
libtouch_filter, libtouch_model

### 实现功能

**按键读取**

MCU时钟读取按键通道状态，再与物理按键相对应

**屏幕驱动**

初始化后向LCD1602发送0x02进入4位模式，把每个字节拆分成高低4位分别发送
**Feature**: 利用CGRAM，在屏幕上显示非ASCII字符

**串口输入模式**

在主界面按Shift+0，进入串口模式
将STM32使用USB连接至电脑后，用串口工具发送任意文本，将显示在屏幕上

**表达式解析**

使用递归下降解析器
支持四则运算、括号处理、根号、指对、三角及复数运算
处理时将所有表达式视为复数，但未开启复数模式将限制输入输出范围为实数域
按Mode进入复数模式后进行正常的复数域运算

**Feature:解一元二次方程**

在主界面按Shift+.进入解方程模式
依次输入a，b，c，按EXE，计算器将给出方程ax^2+bx+c=0的两个根
